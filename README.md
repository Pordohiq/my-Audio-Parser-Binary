# my Audio Parser Binary

Welcome to *my Audio Parser Binary* this is my Project in which I want to achieve
a decoder for all important audio codecs. This will take long and it will not al-
ways work, but it will be my little joy for programming.

## Why?

Why have I decided to go through all of the pain to create a  binary to parse au-
dio files? Well, I have another project that is an audio player (I have first bu-
ilt for Android) and all the audio libraries were big (media3). Now the problem
is that I am pretty much obsessed with storage efficency and the audio player si-
ze of 4.2MB was to big for me. Media3 alone is 1 MB big. So my goal is to create 
a decoder that is smaller than 1MB. Whish me luck...
